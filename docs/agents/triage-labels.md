# Triage labels

Preserve the existing tracker taxonomy and accepted mappings. Only `wontfix` has an exact accepted mapping; a similar category or priority label does not establish another triage state.

| Skill role | Tracker label |
| --- | --- |
| `needs-triage` | Not mapped; obtain an accepted mapping before applying |
| `needs-info` | Not mapped; obtain an accepted mapping before applying |
| `ready-for-agent` | Not mapped; obtain an accepted mapping before applying |
| `ready-for-human` | Not mapped; obtain an accepted mapping before applying |
| `wontfix` | `wontfix` |

Use at most one canonical triage state on an issue. Classification and version-impact labels do not imply readiness. Recheck live labels before mutation. A missing mapping blocks that label edit, not work on an agreed issue.
